PE 投资回报测算 Agent Skill
这是一套供具备联网和计算能力的 AI Agent 使用的工作流程。它根据企业财务预测与拟投资条款，筛选上市可比公司，计算 P/S 和 P/E，并测算不同情景下的退出回报。
怎么用
1. 下载本仓库的 SKILL.md。
2. 把 Skill 和你有权使用的企业财务数据交给支持联网检索的 Agent。
3. 提供拟投资金额、持股或本轮融资条款、预计退出时点，以及你自己设定的经营和退出假设。
可以直接这样问：
请按 SKILL.md 分析附件中的企业，联网筛选上市可比公司，列出估值倍数、数据日期和来源。请按我提供的假设测算三档退出回报，缺失的参数集中列出。
输出
- 可比公司清单、筛选依据及 P/S、P/E
- 保守、中性、乐观三档经营预测与退出估值
- 预计退出回款、投资收益、回报倍数和年化 IRR
订单兑现、财务调整、股权稀释和流动性折价均由使用者按项目设定。缺少关键参数时，流程会标出待确认项。
